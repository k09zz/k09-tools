# K09 Tools

Free, no-sign-up email deliverability tools that run entirely in your browser:

- **[SPF, DKIM & DMARC checker](https://k09zz.github.io/k09-tools/dmarc-spf-dkim-checker/)**: grade a domain A–F with copy-paste fixes.
- **[Email validator](https://k09zz.github.io/k09-tools/email-validator/)**: check up to 100 emails for syntax, MX, disposable domains, role accounts and typos.

DNS lookups use public DNS-over-HTTPS (Cloudflare, with Google as backup). Disposable-domain data comes from the CC0 [disposable-email-domains](https://github.com/disposable-email-domains/disposable-email-domains) list.

Bulk and API versions run on Apify: [Email Validator & List Cleaner](https://apify.com/k09/email-list-cleaner) · [Email Deliverability Checker](https://apify.com/k09/email-domain-audit) · [PDF Table Extractor](https://apify.com/k09/pdf-text-tables) · [Docs to Markdown for AI](https://apify.com/k09/docs-to-markdown)
