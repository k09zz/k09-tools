FAQ

What gets removed?

Scripts, styles, iframes, SVGs, the page head, navigation menus and footers, so you keep the content and lose the clutter.

Are tables supported?

Yes. HTML tables become GitHub-flavored Markdown tables. If a table has no header cells, its first row is used as the header.

Can it fetch a web page for me?

No. It converts HTML you paste or files you have. Only convert content you have the right to use.
